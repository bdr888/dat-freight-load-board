# Implement a Feature

## 1. Understand

- Restate the requested behavior and acceptance criteria.
- Inspect the relevant components, hooks, types, and tests.
- Identify existing patterns to reuse.

## 2. Plan

- Identify the smallest set of files that need changes.
- Consider loading, empty, error, and success states where relevant.
- Identify any accessibility implications.
- Ask questions if a critical requirement is unclear.

## 3. Implement

- Follow the existing project conventions.
- Keep changes focused and avoid unrelated refactoring.
- Prefer existing dependencies and components.
- Add or update tests for the behavior being introduced.

## 4. Verify

- Run the relevant test suite.
- Run linting and type checks if available.
- Fix regressions caused by the change.
- Review the diff for accidental or unrelated changes.

## 5. Report

- Summarize the implementation.
- List files changed.
- Report validation results accurately.
- Mention tradeoffs or outstanding issues.
